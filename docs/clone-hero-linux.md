## Primeiro teste no jogo
1. Iniciar o Guitar Lab e confirmar **Controle criado** no painel.
2. Abrir Clone Hero pelo menu do Zorin.
3. Pressionar **Espaço** no menu principal para abrir o mapeamento.
4. Na parte de controle/gamepad, selecionar/atribuir **Guitar Lab Virtual Controller**, se necessário.
5. Mapear uma entrada, como Green, apertando o botão físico D15.
6. Confirmar que pressionar e soltar correspondem ao comando no jogo; verificar também reconexão.

Com uma única chave, esse teste prova detecção/mapeamento, não uma guitarra jogável. Não marcar M1 concluído apenas pela criação do dispositivo Linux. Interface inicial e mapeamento ainda aguardam validação do usuário.
